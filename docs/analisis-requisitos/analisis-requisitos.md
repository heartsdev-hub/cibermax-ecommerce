## Módulos:

- Módulo de usuarios.
- Módulo de productos.
- Módulo de categorías.
- Módulo de inventario.
- Módulo de pedidos.
- Módulo de pagos.
- Módulo de reportes.

## Requisitos funcionales

| Código | Módulo | Requisito funcional |
| --- | --- | --- |
